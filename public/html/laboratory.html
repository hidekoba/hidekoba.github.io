RESEARCH ENVIRONMENT

研究環境 / Research Environment

本研究室では、海洋・気候・炭素循環の数値モデリングとデータ解析のため、専用の計算サーバーと大容量ストレージを整備しています。モデル開発・テスト計算から、長期間のオフライン海洋物質循環実験、大規模なモデルデータの解析まで、研究室内で実施できる環境を構築しています。

Our laboratory maintains dedicated computing and storage systems for numerical modeling and data analysis of the ocean, climate, and carbon cycle.

COMPUTING

並列計算サーバー (gambero) Parallel Computing Server

モデルの開発、長期積分、感度実験などに利用しています。

  • 128 CPU cores
  • 1 TB memory
  • Ubuntu Server / Slurm

DATA STORAGE

大容量データストレージ (calamari) Data Storage

数値モデル実験や各種観測で生成されるデータの保存・解析のため、研究室では総容量約 680 TB のストレージ環境を運用しています。研究の進展に応じたストレージ拡張も可能です。

  • 約 680 TB usable
  • Expandable storage architecture

共同利用計算環境 National HPC Resources

大規模な気候・古気候シミュレーションには、研究室内の計算環境に加え、JAMSTEC 地球シミュレータや東京大学最先端共同 HPC 基盤施設（JCAHPC）のスーパーコンピュータシステムなど、国内の共同利用計算資源を活用しています。

Computationally intensive climate and paleoclimate simulations are complemented by national shared high-performance computing resources in Japan.
